# 紫微斗数排盘 · 天命星盘（ziwei-pan）

输入公历生辰与时辰，排出完整紫微斗数十二宫命盘：四柱、命身宫、十四主星、四化、辅星、命主身主与大限。**零依赖单页应用**，打开 `index.html` 即可使用。

在线体验：https://git-mark123.github.io/ziwei-pan/

## 功能

- 公历（年月日）+ 时辰 → 农历、四柱、十二宫命盘
- 五行局（金四局 / 木三局 / 水二局 / 土五局 / 火六局，命宫干支纳音定局）
- 十四主星（紫微星系、天府星系）与四化（禄权科忌）
- 辅星：左辅右弼、文昌文曲、天魁天钺、禄存擎羊陀罗、火星铃星、地空地劫、天马
- 命主、身主；大限（起限岁数 = 五行局数，阳男阴女顺行、阴男阳女逆行）
- 玄幻星穹神话风格盘面，响应式适配手机

## 快速开始

```bash
# 本地打开
open index.html
```

或启动任意静态服务器：

```bash
npx serve .
```

## 算法依据

- 安星法口诀：王亭之《中州派紫微斗数》安星诀（明灯易学整理转载：[新浪文章](https://k.sina.com.cn/article_6438481125_17fc36ce5001002xcd.html)）
- 排盘步骤：《紫微斗数精成》第二章 排盘方法（[国学大师网](https://m.guoxuedashi.com/a/22567xtdb/285467d.html)）
- 农历 / 节气数据（1900–2100）：开源项目 [solarlunar](https://github.com/JJonline/solarlunar)（MIT License）

### 口径说明

| 项目 | 默认口径 | 可选 |
| --- | --- | --- |
| 年柱年界 | 立春（排盘主流） | 正月初一 |
| 闰月 | 中州派：闰月十五（含）前作上月、十六后作下月 | 精成：闰月一律作下月 |
| 四化 | 通行版（甲廉破武阳、乙机梁紫阴、丙同机昌廉、丁阴同机巨、戊贪阴右机、己武贪梁曲、庚阳武阴同、辛巨阳曲昌、壬梁紫左武、癸破巨阴贪） | 戊 / 庚 / 壬三干各派口诀存在分歧，已注明 |

## 验证

- 起紫微星表 **150 格全量校验**（5 局 × 30 日）通过
- 王亭之《中州派》命例完整校验：1977 丁巳年五月寅时男命（命宫甲辰、身宫戊申、火六局、大限逆行 6 岁起）全部一致
- 四柱与 [solarlunar](https://github.com/JJonline/solarlunar) 交叉核对一致
- 与开源紫微斗数排盘库 [iztro](https://github.com/SylarLong/iztro) 交叉验证 5 张命盘（含闰月），十二宫主星 / 辅星 / 宫干支完全一致

```bash
npm install
node test.js
```
